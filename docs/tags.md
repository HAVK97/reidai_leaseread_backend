# Semantic tags — keyword reference

## Repairs & decoration

Signals for routing and tagging lease content about tenant repair covenants, decoration cycles, dilapidations, schedules of condition, reinstatement, and related compliance.

### Heading / caption keywords

Use as high-precision caption signals where they appear in clause or schedule titles.

| Keyword |
| --- |
| Repair |
| Decoration |
| Redecoration |
| Dilapidations |
| Reinstatement |
| Yielding up |
| CDM |

Avoid **`Yielding`** alone (matches rent and other “yielding” uses).

### Multi-word phrases — secondary / context-dependent

Strong when paired with another repair/decoration signal; weak alone.

| Phrase | Note |
| --- | --- |

| Clean and tidy | Very generic |

| Last three months | Generic temporal trigger |

### Topic overlap

- **Reinstatement** may co-occur with **alterations** (reinstatement of alterations).
- **CDM** / **Health and safety file** cluster together on construction safety.
